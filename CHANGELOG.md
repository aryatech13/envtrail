## 0.1.0 - 2026-07-27

### Added

- Multi-language environment-variable source scanners.
- `.env` template documentation scanner with value redaction at the boundary.
- Dockerfile, Compose, GitHub Actions, GitLab CI, and Kubernetes providers.
- Drift rules, health scoring, ignore patterns, and JSON configuration.
- Terminal, JSON, Markdown, SARIF 2.1.0, and standalone HTML reports.
- Bundled GitHub Action with annotations and summary outputs.
- Tests, CI, release automation, community templates, and launch artwork.

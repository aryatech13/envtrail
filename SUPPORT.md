# Support

- Use **GitHub Discussions** for questions, examples, and adapter design.
- Use the **bug report** template for reproducible false positives or crashes.
- Use the **feature request** template for new formats and integrations.
- Use private vulnerability reporting for security concerns.

Include the EnvTrail version, Node.js version, operating system, command, and a
minimal sanitized fixture. Never attach a real `.env` file or credential.

# Roadmap

EnvTrail's direction is shaped in public. Items are candidates, not promises.

## Next

- Framework wrappers: Zod, envalid, pydantic-settings, Spring, and Rails.
- Terraform, Helm values, and additional hosted deployment adapters.
- Monorepo workspaces with per-package documentation coverage.
- Baseline files for gradual adoption in large repositories.
- PR annotations that show only newly introduced drift.
- A formal adapter plugin interface.

## Later

- Optional language-parser integrations for higher-fidelity locations.
- A reusable provenance badge backed by CI artifacts.
- VS Code diagnostics from the JSON result.
- Comparative reports across branches without sending source off-device.

## Explicit non-goals

- Reading or validating live secret values.
- Becoming a secret manager.
- Executing application code to discover configuration.
- Guessing dynamic keys without evidence.

Open an issue to propose or claim an item. Maintainers will label small,
self-contained tasks as `good first issue`.
